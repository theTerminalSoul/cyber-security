1. **Sets Up and Closes Connections:** It opens, manages, and tears down communication sessions between Presentation layer entities.
2. **Keeps Data Isolated:** It keeps each application's data separate so that different processes on your computer do not mix up their communications.
3. **Handles Multiple Sessions:** It allows you to run multiple independent sessions of an application at the same time (for example, opening multiple browser tabs or windows simultaneously).
4. **Controls Dialogue:** It coordinates communication between systems and determines how devices take turns talking.
    
5. **Provides Three Communication Modes:**
    - **Simplex:** One-direction communication only.
    - **Half-Duplex:** Two-way communication, but only one direction at a time.
    - **Full-Duplex:** Simultaneous two-way communication.
